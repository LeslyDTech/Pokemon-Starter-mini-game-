# Pokémon Starter Selector

A simple Python program that lets you choose your starter Pokémon from the classic Generation 1 trio.

## Features

- Choose from the original three starter Pokémon: **Bulbasaur**, **Charmander**, or **Squirtle**
- Not sure who to pick? Use the **random** option to let fate decide

## Usage

Run the script with Python:

```bash
python pokemon.py
```

You'll be greeted with a menu:

```
Welcome to the world of Pokemon!
Please choose your starter Pokemon:
1. Bulbasaur
2. Charmander
3. Squirtle
Or type 'random' to get a random starter
```

Enter `1`, `2`, or `3` to pick your starter, or type `random` to get one assigned to you.

## Requirements

- Python 3.x
- No external dependencies — uses only the built-in `random` module
